# Golf Trip Application — MVP

## Run locally
1. Install Node.js 20+.
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000

This is a functional front-end MVP with responsive admin screens for dashboard, players, rounds, matches, schedule, settlements, notifications, and settings. The next implementation step is connecting PostgreSQL/Supabase authentication, persistence, realtime scoring, PWA/offline storage, and production deployment.
